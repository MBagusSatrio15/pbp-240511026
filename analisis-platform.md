# Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa utama** | JavaScript, HTML, CSS, TypeScript (PHP di backend) | C++, C#, Java, Python | Kotlin, Java (Android), Swift (iOS), Dart |
| **Arsitektur** | Client-Server (Browser sebagai client) | Standalone, Client-Server | Standalone, Client-Server berbasis API |
| **Cara distribusi** | URL/Domain via Web Browser | Installer (.exe), Microsoft Store | Google Play Store, App Store |
| **Keunggulan** | Multi-platform, tanpa instalasi manual, update instan | Performa tinggi, bisa offline | Portabel, akses langsung ke sensor (GPS, Kamera) |
| **Keterbatasan** | Bergantung koneksi internet, akses hardware terbatas | Harus spesifik OS (Windows/Mac), update manual | Layar terbatas, memori dan baterai lebih kecil |
| **Contoh aplikasi** | SIAKAD, Gmail web, balikbarang_rental | MS Word, VS Code | WhatsApp, Gojek |

### Refleksi

Platform yang paling menarik bagi saya untuk dipelajari saat ini adalah platform Web dan Mobile. Sebagai mahasiswa Teknik Informatika yang sudah terbiasa dengan pengembangan web menggunakan PHP dan MySQL, mempelajari arsitektur ini memberikan perspektif baru tentang bagaimana sebuah layanan menjangkau pengguna. Platform mobile sangat menantang karena menuntut efisiensi resource seperti baterai dan memori, serta cara memanfaatkan sensor bawaan perangkat.

Tantangan terbesar saat melakukan setup environment adalah memastikan semua variabel path (khususnya untuk Java JDK) terkonfigurasi dengan benar agar bisa terbaca di terminal. Selain itu, manajemen ruang penyimpanan juga menjadi isu, terutama untuk instalasi Android Studio yang membutuhkan memori sangat besar beserta emulatornya.

Untuk mengatasi tantangan tersebut, rencana saya adalah selalu merujuk pada dokumentasi resmi instalasi dan mencari solusi di forum komunitas seperti StackOverflow jika menemukan pesan error pada terminal. Saya juga akan membersihkan file sampah (cache) di laptop secara berkala untuk memastikan penyimpanan cukup untuk kebutuhan Android Studio ke depannya.
